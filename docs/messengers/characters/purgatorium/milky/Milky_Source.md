## concept

* 밀키 기획 이전에는 [버디](../buddy/Buddy_Header.md)의 일부로 구상되었다.
  - 오른팔 대신 사슬팔을 사용하는 소녀로 구상되고 있었다.
    + [버디](../buddy/Buddy_Header.md) 본체를 오른팔 대신 장착하여 사용하고, [버디](../buddy/Buddy_Header.md)의 동력이 되는 등, 폼 체인지를 구상했다.
    + *Devil May Cry* 시리즈의 *Nero*, *SANABI*의 *Protagonist* 등에서 겹치는 요소가 많았고, 독창성이 부족해지면서 결국 구현되지 않았다.
* *갓 슬레이어* 세계관에서는 *페록스(Ferox)* 캐릭터가 구상되고 있었으나, 무산되면서 해당 설정이 [홀스터](./Milky_Header.md#holster)와 [멀티폴](./Milky_Header.md#multipole) 설정에 융합되어 구현되었다.
  - *섬유 머신(Fiber-Machine)* 검사 사이보그이다.
  - *도력검* 장비를 사용한다.
    + 광선검처럼 칼자루에 칼날을 수납한다.
    + 심볼형 에너지 코등이를 전개한 후 에너지 칼날을 생성한다.
    + 오른손에는 청색 대도를 정수로 쥔다.
    + 왼손에는 적색 소도를 역수로 쥔다.
  - *제트파워블레이드팩(Jet-Power-Blade-Pack)* 장비를 사용한다.
    + 기본적으로는 제트팩이다.
    + 도력검을 두 자루 수납하면 자색으로 변한다.
    + 도력검을 날개 형태로 전개하여 비행한다.
    + 대도는 위로, 소도는 아래로 향하고, 검집의 기계팔이 자동 공격한다.    
  - 보라색 가죽 재킷, 검은 셔츠 등의 포인트를 사용한다.
* 밀키는 [버디](../buddy/Buddy_Header.md)로부터 분리되면서 안티테제로 기획되었다.
