### black-magic-book

* **금지된 마법**
  - 수호하면 능력치가 상승한다.
  - 사용하면 *흑요석 골렘* 군대를 소환할 수 있다.
  - 사역마 *메피스토텔레스*의 조언을 들으면 무조건 패배한다.

### panteach-armor

* **판다는 죽어서 가죽을 남긴다**
  - [판스](../../characters/panda_corporation/panteach/PanTeach_Header.md#absolute-evasion) 사후 그의 가죽으로 만든 방어구다.

  - 손상되어도 자동으로 복구된다.

* **최강의 마정석**

  - 일시적으로 마법을 생성한다.

### awakening-skill

* **그대들은 총력전을 원하는가**
  - 호출자의 위치로 *윙콕 가족* 전원이 순간 이동하며, 거대한 마차가 소환된다.
  - [시바](../../characters/wingcorg_family/shibal/Shibal_Header.md)가 [해맑은 스텝](../../characters/wingcorg_family/shibal/Shibal_Header.md#cheerful-step)으로 마차를 끈다.
  - [플라나리아](../../characters/wingcorg_family/planaria/Planaria_Header.md)가 [지옥의 조교 스텝](../../characters/wingcorg_family/planaria/Planaria_Header.md#step-of-hell-assistant)으로 마차를 끈다.
  - [원원이](../../characters/wingcorg_family/wonwonyee/WonWonYee_Header.md)가 [두더지 뿅](../../characters/wingcorg_family/wonwonyee/WonWonYee_Header.md#whack-a-mole)으로 마차 주변을 공격한다.
  - 마차 위에서 [북극이](../../characters/wingcorg_family/arcticy/Arcticy_Header.md)가 [무자비한 박치기](../../characters/wingcorg_family/arcticy/Arcticy_Header.md#ruthless-headbutt)로 돌격한다.
  - [윙키](../../characters/wingcorg_family/wingcorgi/WingCorgi_Header.md#wingky)가 마차 주변을 공전하며 포격한다.
