# PickupMan Main

---

## characteristics

> *습득맨은 다른 차원에서 [윙콕 유니버스](../../../core/wingcorg_universe/WingCorg_Universe_Header.md)를 침략한 특수부대이다.*
>
> *습득한 능력을 매번 초기화하고 등장해서 깡패들에게 처맞는다.*

> *습득맨의 대표적인 슬로건은 다음과 같다.*
>
> *"폭행을... 습득했다..."는 깡패들에게 맞으면서 습득한 전투 능력이다.*
>
> *"칼빵을... 습득했다..."와 "총알을... 습득했다..."는 깡패들에게 죽어가면서 습득한 살상 능력이다.*

> *습득맨은 집중력이 낮기 때문에 다채로운 공격에 취약하다.*
>
> *이도 저도 아니다 싶으면 그냥 저 나불거리는 주둥아리를 막아보자.*
