# Pickup-Man Main

---

## characteristics

> *습득맨은 다른 차원에서 [윙콕 유니버스](../../../core/wing-corg-universe/Wing-Corg-Universe_Header.md)를 침략한 특수부대이다.*
>
> *등장할 때마다 습득한 능력을 망각하는 바람에 깡패들에게 처맞는다.*

> *습득맨의 대표적인 슬로건은 다음과 같다.*
>
> *"폭행을... 습득했다..."는 깡패들에게 맞으며 습득한 전투 능력이다.*
>
> *"칼빵을... 습득했다..."와 "총알을... 습득했다..."는 깡패들에게 죽어가면서 습득한 살상 능력이다.*
